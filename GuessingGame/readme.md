## Guessing Game
Think of a data structure and answer quizzical questions that helps you recall/learn information about it as well as allows the computer to guess what you have thought of. 
In a particular play, this game takes in extra questions and answers and keeps building on top of the information it already has, in case that pair of question and answer was missing/ not ocrrect.

Such adaptive learning techniques can be useful in helping students test their knowledge on a wide variety of topics.
