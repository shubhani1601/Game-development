# Tic Tac Toe
A depiction of Perfect Minimax algorithm for Tic Tac Toe game where the computer never loses. 

# Steps to run module: 
1. Run the command 'mvn clean install' to set up and install all dependencies from the maven repository.
2. Run the command 'mvn javafx:run' to trigger the game play.
3. A grid should appear and user will be able to choose a cell and place the 'X'. The game continues!
